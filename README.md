# PianoABC 🎹

An educational piano learning game developed with Godot.

## Features

### 🎵 Learning Mode
Learn songs step by step, for example "Für Elise".

### 🎹 Free Play Mode
Children can freely play the piano and experiment with different melodies.

### 🏆 Challenge Mode
Players have to reproduce played melodies and improve their skills.

## Technologies

- Godot Engine
- GDScript
- Git
